## 維持するmain側の変更

mainには本番配備後の認可強化があります。元のOAuth Grant・現在のFirebase本人情報・失効の再検証、人間の修正依頼をMCPが代行することの拒否、サーバー計画に一致するワーカー入力、ホスト上の生成コード実行の制限を保持します。これらを以前の本番コードで上書きしません。

依存関係はmainのNext.js / eslint-config-next 16.3.8を維持します。本番の16.3.6への降格は行いません。GHSA-vfj7-8cjw-p6xmの承認済み監査例外は2026年10月16日JSTまでで、10月17日00:00 JSTから期限切れです。[監査方針](AUDIT_POLICY.md)とIssue #107で追跡します。

## 私有資材からの候補作成

1. 最終mainのSHAと作業ツリーを確認する。
2. 私有保全コピーから、動画カタログの13本を無視対象の `src/assets/help-videos/` へ復元する。秘密鍵・実トークン・ワーカー状態・非公開成果は復元先のGit対象へ入れない。
3. `npm run release:prepare -- /PRIVATE_LOCATION/NEW_CANDIDATE` を実行する。出力先はリポジトリ外の新規ディレクトリとする。
4. 生成されたmanifestのファイルSHA256とGit状態を確認し、候補でビルド・関連検証を行う。失敗してmanifestが完成していない候補は配備に使用しない。
5. 本番反映を行う場合は、その候補の確認結果と [本番反映手順](PRODUCTION_RELEASE_RUNBOOK_2026-09-18.md)に従って別途実行する。

私有資材を含む候補、配備ZIP、manifest、運用ログは公開リポジトリや公開Releaseへ添付しません。自動配備を設定する際も、録画の私有供給と内容検証を先に組み込みます。
