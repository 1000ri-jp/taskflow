# 今月の的（自動おすすめ・暫定版）

- AI接続は認証待ちのため、ユーザー承認済みのルールによる暫定表示。AIモデルを呼び出した結果ではなく「自動おすすめ」と明示する。
- `/my-dashboard` の「今月の的」で、選択された各プロジェクトから最大3件を自動掲載する。タスクの手動選択ボタンは表示しない。件数が不足しても架空タスクで埋めない。
- 対象は同じプロジェクトの未完了タスク。完了・中止・アーカイブ済みと、開始日が来月以降のタスクは除外する。
- 期限（当日・7日以内・期限超過・今月）、優先度、開始日、後続タスク数で採点する。期限超過の日数が長いほど無制限に優先される仕組みにはしない。
- 前提タスク未完了・不明の候補は後順位にする。候補に残った場合は「前提タスクの完了待ち」を表示する。別プロジェクトのタスクで依存完了を判定しない。
- 選出理由を短く表示し、開始日を迎えたことだけで「作業中」と断定しない。同点は期限・ID順で安定させる。
- 既存の `useMyTasks().allProjectTasks` の購読結果を使用する。タスク更新で再計算し、日付・月の変化は毎分およびウィンドウ復帰時に確認する。新たなAPIやFirebaseコレクションは追加しない。
- 読み込み中は候補を隠し、取得エラー時は部分取得であることを表示する。元タスクの書き込みや通知送信は行わない。
- プロジェクト表示設定 `taskflow.targetProjects.v1` は維持する。旧手動選択の `taskflow.targetTasks.v1` は自動表示では参照も上書きもしない。旧選択用コンポーネントとストアは切り戻し用に残しているが、ダッシュボードからは呼び出さない。
- 元タスクのリンクは既存の詳細画面に移動する。

## 達成目標（人数カウント）

- 「今月の的」とは別の独立した「達成目標」カードから、人数単位の目標をブラウザだけに保存できる。
- 目標人数と達成条件を設定する。達成条件は応募・注文受付・鑑定開始・鑑定書完成・納品・指定タスク完了から選ぶ。
- 各人数枠には、達成条件を表すタスクをプロジェクトをまたいで1件紐づける。元タスクの完了状態を読み取り、完了人数を `1/3` のように表示する。
- カードには人数分の人型アイコンを目標名の横へ横並び・折り返しで表示する。達成済みは紫の塗りとチェック、設定済み未達は薄紫の実線、未設定または取得不能は灰色の破線で区別する。「1人目」などの縦行と達成条件の文言は表示せず、設定済みアイコンから元タスクを開ける。達成条件は編集画面と保存データだけに維持する。
- 目標が複数ある場合は、広い画面では2列、狭い画面では1列で表示する。
- 初期目標は「ココナラモニター獲得」、3人、「ココナラで注文を受けたとき」。タスクは自動作成せず、設定画面で選ぶ。
- この版の目標設定は個人のブラウザ保存で、Firebaseへの共有・同期は行わない。紐づけ先が削除・アーカイブ等で取得できない場合は未達として扱い、表示できないタスクと知らせる。
