# 自動アーカイブの期間設定・プレビュー

プロジェクトの「設定」→「完了タスクの自動アーカイブ」に配置。

- 現段階はプレビューのみ。自動実行・共有書き込み・サーバースケジュールは追加していない。
- 期間は30日（初期値）、7日、任意の1〜3650日、OFF。1日は完了日時から24時間。ユーザーが明示的にOFFを保存した場合は、再読み込み後もOFFを維持する。
- `taskflow.autoArchivePreview.v1` にユーザーIDとプロジェクトIDをキーとして期間だけを保存。共有Project/Taskのフィールド追加なし。
- 非アーカイブの実タスクを読み取り、完了済み・有効な完了日時あり・期間経過の条件で候補表示。未完了、完了日不明、他プロジェクトを除外する。
- 判定時点は取得完了時の端末時刻。自動実行予定日時ではない。「プレビューを更新」で最新データと判定時刻を更新する。
- 保存失敗、通信失敗、オフラインを空の正常結果と区別して表示する。

## 将来の本実行（別途承認・設計が必要）

共有ポリシーの保存先と管理者権限、サーバーの定期処理・時刻、実行直前の完了状態の再確認、冪等性、監査、復元後の自動再対象化を防ぐ仕組みが必要。
既存の手動復元では復元履歴が残らないため、現状のプレビューから「過去に復元したタスク」を識別できるとは扱わない。
ブラウザ用のプレビュー設定を、ユーザーの承認なく共有自動処理へ流用しない。
